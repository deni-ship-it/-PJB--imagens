# 🖼️ Importando Imagens no Power BI utilizando Google Sheets

Este repositório demonstra uma forma simples, performática e de fácil manutenção para exibir imagens no **Power BI** utilizando uma **planilha do Google Sheets** como tabela auxiliar.

## 📌 Vantagens

- ✅ Atualização automática das imagens
- ✅ Não aumenta significativamente o tamanho do arquivo `.pbix`
- ✅ Fácil manutenção
- ✅ Funciona tanto no Power BI Desktop quanto no Power BI Service
- ✅ Dispensa armazenar imagens dentro do modelo de dados
